# Z50 调色实验室

第一代 Nikon Z50 的浏览器 Picture Control 调试工具。照片在浏览器内处理，不上传到服务器，不保存进源码；预设可以保存在当前浏览器，或导出为 JSON。

[打开网页](https://city0928.github.io/nikon-z50-picture-lab/)

推送到 `main` 后，GitHub Actions 会先执行语法检查与相机导出测试，再自动部署 `dist/` 到 GitHub Pages。

## 使用

1. 上传 JPEG、PNG 或 WebP 照片，选择风格起点，调整参数和色调曲线。
2. 点击「导出到 Z50」，设置相机预设名称（最多 19 个 ASCII 字符）和文件编号（01–99）。
3. 下载 SD 卡 ZIP，把其中的 `NIKON` 文件夹复制到 SD 卡根目录。文件路径为 `NIKON/CUSTOMPC/PICCONxx.NP3`。
4. 在 Z50 的「照片拍摄菜单 → 管理优化校准 → 载入/保存 → 复制到照相机」中，选择文件并保存到空闲的 C1–C9。

导出同名编号前请检查 SD 卡现有文件，避免覆盖自己的预设。

## 范围与验证

- 导出真实二进制 NP3 0300 文件及包含正确目录的 SD 卡 ZIP。
- 支持基础优化校准、锐化、中范围锐化、清晰度、对比度、亮度、饱和度、色相、部分自动参数、单色滤镜和自定义色调曲线。
- 影调面板提供曝光、亮度、对比度、高光、阴影、白色、黑色。所有调整合成为 NP3 导出曲线；不是预览专用功能。曝光 EV 模拟明暗，不改变相机拍摄曝光，高光/阴影不能恢复已经丢失的细节。
- JSON 保留每个影调滑块的可编辑数值；NP3 保留最终合成曲线，重新导入时各影调滑块归零，避免重复应用。
- 色彩调整为全局色相和饱和度。独立绿色、黄色、青色等分色 HSL 属于更丰富的色彩处理，无法完整转入第一代 Z50 的经典 NP3；本工具不显示这类无法导入的控件。
- 支持导入本工具 JSON 和受支持的 NP3 0300 文件；拒绝不支持的后代版本和色调设置，避免静默丢失参数。
- 网页预览是近似处理，无法复现尼康专有机内算法。已处理的 JPEG 会叠加调整。最终效果以相机试拍为准。
- 白平衡、ISO、曝光补偿、光圈和快门不属于本文件中的 Picture Control 设置，需要在相机上另行调整。
- 已验证二进制结构、参数往返、自定义曲线、ZIP CRC 和目录；尚未在实体 Z50 上验证导入。

## 本地运行

需要 Node.js 18 或更新版本，无第三方依赖。

```sh
node preview.mjs
node --test tests/core.test.mjs
```

预览地址为 `http://127.0.0.1:4173/`，静态页面位于 `dist/`。
